# Projet Bioinformatique- Analyse des Copies d'Éléments Transposables

>**Code R:**
\t histv2.r
Contient la fonction histtrnspsn(fam), qui permet d'obtenir le nombre de copies d'une famille fam, leur histogramme en fonction de leur taille et leur statistique.

>**Codes Bash:**
\t mkblastdb.sh
Permet d'initialiser la base de donnees, doit etre execute avant famblast
Tester avec: ATET_full.fasta
\t famblast
Flux de travail pour obtenir les resultats de blast pour une famille requetee
Tester avec: brodyaga1a.fasta
